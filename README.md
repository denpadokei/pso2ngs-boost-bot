# PSO2NGS ブーストキャンペーン Discord 通知（共有Bot）

『PSO2 ニュージェネシス』の**ブーストキャンペーン**（レアドロップ倍率アップなど）を検知して、
Discord のチャンネルへ自動投稿する Bot です。**この Bot は既に運用中で、招待するだけで使えます。**

- 新しく告知されたブーストを通知
- 開始日・終了日（通常は水曜）の実行時にリマインド
- 対象クエスト、全プレイヤー／プレミアムの倍率差も表示
- Discord の**スケジュールイベント**（RSVP 付き）も自動作成・更新
- 常駐サーバー不要（毎週水曜 13:00 JST に自動実行）

## 使い方

### 1. Bot をサーバーに招待する

「サーバーを管理」権限を持つメンバーが、次の URL を開いてサーバーを選びます。

```
https://discord.com/oauth2/authorize?client_id=1572407928101806202&scope=bot&permissions=17600775982080
```

### 2. 通知先チャンネルを設定する

**スラッシュコマンドでの設定がおすすめです。** サーバー内で次を実行します（管理者のみ）。

```
/setup #通知先チャンネル
```

設定が完了すると「✅ 通知先を #チャンネル に設定しました」と返ります。

**ブラウザ（OAuth）からでも設定できます。** 次のページで Discord に認証して
サーバーとチャンネルを選んでください（コマンドが使えない場合の代替手段です）。

```
https://pso2ngs-boost-bot.azurewebsites.net/api/setup
```

### 3. 通知を待つ／今すぐ反映する

毎週水曜 13:00 (JST) に、新着・開始・終了の通知とスケジュールイベントの作成・更新が行われます。
次の水曜まで待たずに反映したい場合は、設定完了ページの「今すぐイベントを同期する」ボタンで
即時同期できます。

Bot をサーバーから抜くと、次回のバッチで自動的に停止します。
再度使いたい場合は、手順 1・2 をやり直してください。

## 届く通知の例

```
!~Event Announcement~!
Name: ブーストキャンペーン 第1弾
Description: ・レアドロップ倍率+100%
             ・プリセット能力付与倍率+50%
Start (Local): 2026年11月11日 水曜日 12:00
End (Local):   2026年11月18日 水曜日 11:00
Location: アークス双陣杯 / 星砕の暴進
Event ID: 79c8704046d6
```

開始・終了リマインドでは `【本日から】` / `【本日まで】` が付きます。
